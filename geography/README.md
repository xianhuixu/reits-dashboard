# 底层资产地理索引

核查日期：2026-09-28。53只基金、40个城市/州/地区、76条基金—城市关联；站内行情样本88只。**部分覆盖，不是完整当前持仓数据库。**

## 数据口径

- `locations.json`独立于行情与财务原始数据。每条记录明确基金代码、底层资产名称、所在地及来源；不是按基金名称、基金管理人或原始权益人总部定位。
- 按地级市归并，直辖市单列；昆山归苏州、腾冲归保山。跨市线性工程拆成多个城市条目，不绘制未经核验的线路。
- 同一基金同一城市仅一条关联；省级排名在省内再次按基金代码去重。不同城市/省份可以包含同一基金，不能相加为基金总数。不得据此计算资产价值、收入或现金流地域占比。
- 来源包括管理人、原始权益人、交易所公告、项目律师及同花顺F10。每条来源包含`kind`、`basis`和查阅日期。`checkedAt`是本次查阅日期，不是来源披露日或资产交割日；`basis`载明资产范围时点。
- 历史首发和扩募材料只支持该时点的资产范围。部分最新扩募未纳入，不能将条目标识为已完成最新持仓核验。京东合肥/西安、润泽A-7/A-8等拟扩募项目未在本索引确认交割，因此暂不收录。
- 中航易商F10页混有招商科创项目，未采用；宝湾采用年度报告的天津/南京/嘉兴三处资产，未采用早期方案的廊坊资产。安徽交控的终点“大渡口”归池州，不按公路名称误归安庆。
- 35只未收录基金由行情样本与索引差集动态产生，页面显示待补充清单。新上市基金不会获得默认或猜测坐标。

## 地图与坐标

- 底图：[阿里云DataV GeoAtlas](https://datav.aliyun.com/portal/school/atlas/area_selector)，原始文件 `https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json`，2026-09-28获取。保留所有原始几何及南海诸岛附图，未自行绘制行政边界。
- 城市示意坐标取 `https://geo.datav.aliyun.com/areas_v3/bound/100000_full_city.json` 的 `properties.center`；直辖市取省级数据对应center。精度字段固定为`city`，不代表项目建筑或工程的精确坐标。
- 使用相同线性经纬度投影展示底图和点位，属于地域分布示意，不用于导航、测距或面积计算。底图在仓库本地托管，访问网站不调用第三方地图API、不需要密钥。

## 维护与验证

新增记录前查阅项目公告或运营资料，确认实际底层项目位置、是否已经交割、资产范围时点。优先用最新定期报告替换二手资料；修订地理元数据不改变任何金融指标。每个来源链接直接指向使用的文件/页面。

`node --test tests/geography.test.js`验证来源、坐标范围、唯一关联、跨市省级去重、组合筛选和不制造默认地点。`npm test`运行全站测试。新增目录已加入全部Cloudflare部署复制路径；GitHub Pages直接发布main。
