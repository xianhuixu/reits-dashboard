## REITs Dashboard 10Y 国债收益率显示旧数据问题

### 问题
用户反馈网站上 10Y 国债收益率仍显示 7/27 的旧数据（1.73%），没有同步更新到 8/11 的最新数据（1.7%）。

### 排查过程
1. 检查 cron 任务 → 当前无定时任务配置
2. 检查 git log → 最新提交 86f77a0 (8/11 15:06) 已更新数据
3. 检查 cycle_judgment.json → 本地文件已更新：updated=2026-08-11, bond10y=1.7
4. 通过浏览器截图排查 → 发现"配置建议与风险"标签页中的三张宏观指标卡片（PMI、CPI、10Y国债）为硬编码 HTML，不会随数据文件自动更新
5. 同时发现"多维研究分析"标签页中股息率溢价标尺也硬编码了 2.7%

### 根因
index.html 中的部分数据展示区域使用静态 HTML 硬编码，而非从 cycle_judgment.json / data.js 动态读取。

### 修复内容
1. 将"配置建议与风险"中三张宏观指标卡片改为从 `D.cycle` 动态渲染：
   - 制造业 PMI：D.cycle.pm.pmi
   - CPI 同比：D.cycle.pm.cpi
   - 10Y 国债收益率：D.cycle.bond10y
   - 日期：D.cycle.updated（格式化为 M月D日）
2. 股息率溢价标尺改为动态计算：
   - 使用 D.cycle.bond10y 替代硬编码 2.7%
   - 在 cycle_judgment.json 中新增 avgYield 字段（4.44）
3. 日期显示格式优化：去掉前导零（"8月11"而非"08月11"）
