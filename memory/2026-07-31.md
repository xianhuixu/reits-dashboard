### 服务器环境限制
- **东方财富/同花顺直接访问**：服务器 IP 被屏蔽（curl 000，akshare 连接失败）
- **Yahoo Finance**：限流（429）
- **stock_finance_data API**：仅可通过 OpenClaw 工具调用，无法从纯 Python 脚本直接调用
- **结论**：服务器端目前只能可靠运行 fetch_news.py，行情数据仍需本地 Mac + iFinD 维护
