# REITs Dashboard 一体化固定导航设计规格

## 目标

将品牌区、一级导航和当前页面的二级 Tab 整合为同一个固定导航容器，解决二级 Tab 与顶部导航分离、滚动定位不稳定、按钮层级不清的问题。视觉风格保持简洁、现代、扁平，延续现有浅色金融投研工作台体系。

本次仅调整导航结构、样式和交互状态，不修改行情、财务、新闻、公告或策略数据。

## 已确认方向

- 采用方案 A：品牌、一级导航、二级 Tab、搜索和主题切换共同组成一体化固定工作台。
- 二级 Tab 中的数字序号全部移除；页面正文中的章节编号保留。
- 保持现有三大一级模块及其二级模块名称、顺序和业务逻辑不变。
- 保持现有主模块滚动位置记忆和显式锚点平滑滚动逻辑。

## 信息架构

### 第一层：品牌与主操作区

导航第一行分为四个区域：

1. 品牌区：缩小 Lion 标志，保留“REITs 投研工作台”，右侧增加细分隔线，使其与导航操作区明确区分。
2. 一级导航：市场全景、多维研究分析、配置建议与风险。使用扁平文字 Tab，激活状态采用强调色文字和底部短线，不使用描边胶囊。
3. 全局搜索：保留个券名称/代码搜索，使用低对比度填充输入框。
4. 主题切换：保留白天、护眼、夜晚三种模式，使用紧凑分段控制，降低视觉权重。

### 第二层：上下文二级导航

二级 Tab 直接置于同一导航容器的第二行，不再作为独立粘性元素存在。

- 第二行采用浅灰背景和顶部细分隔线，与一级导航形成层级差。
- 二级 Tab 使用 6px 小圆角矩形，默认透明、激活时使用浅强调色填充与强调色文字。
- 不使用阴影胶囊或大面积高饱和填充。
- 二级 Tab 保持横向滚动和滚动吸附，在小屏幕上不换行、不挤压正文。
- “大类策略配置建议”“短期交易战术”“中长期配置建议”去除数字序号。

### 数据更新时间

“更新日期、最新交易日、覆盖数量、数据来源”从二级导航行移至导航下方的普通内容信息条，不参与固定，避免长文本压缩二级 Tab。

## 固定与滚动行为

- 仅一体化导航容器使用 `position: sticky`；二级导航不再单独设置 `sticky` 或硬编码顶部偏移。
- 导航容器固定在视口顶部并统一管理层级和阴影，避免一级、二级导航滚动时互相覆盖。
- 主模块切换继续保存和恢复各模块滚动位置。
- 二级 Tab 点击后保持现有模块切换或显式锚点跳转行为。
- 页面内容在文档流中自然位于导航之后，不通过固定高度占位或脚本计算头部高度。

## 视觉系统

- 导航容器：白色面板、1px 中性边框、8px 圆角、轻量阴影。
- 品牌区：深色主文字，Logo 控制在桌面 44-48px、手机 34-38px。
- 一级导航：14-15px、600-650 字重；激活状态为强调色文字 + 3px 底线。
- 二级导航：11.5-12px、500 字重；激活状态为浅蓝底 + 蓝色文字。
- 控件圆角：搜索框、主题分段、二级 Tab 统一使用 6-8px，取消不必要的全圆角胶囊。
- 动效：激活线和背景切换控制在 160-220ms，使用现有缓动曲线；遵循 `prefers-reduced-motion`。
- 白天、护眼、夜晚三套主题均复用现有颜色变量，不新增独立色板。

## 响应式布局

### 桌面端

- 第一行高度约 64px：品牌、一级导航、搜索、主题切换单行排列。
- 第二行高度约 42px：二级 Tab 横向排列。
- 整体固定高度约 106px，明显低于当前品牌 Logo 造成的高占用。

### 手机端

- 第一行：紧凑品牌区 + 搜索框。
- 第二行：三个一级 Tab + 紧凑主题分段控制。
- 第三行：可横向滚动的二级 Tab。
- 总高度控制在约 132-140px；一级和二级 Tab 均不换行，不产生页面级横向溢出。

## 状态与可访问性

- 一级与二级 Tab 均保留键盘焦点样式。
- 当前一级模块和当前二级模块同步设置可识别的激活状态；实施时补充或更新 `aria-current`。
- 横向滚动区域保留滚动吸附和边缘提示。
- 搜索、主题切换及导航按钮在白天、护眼、夜晚主题下保持可读对比度。

## 实施边界

- 继续使用现有原生 HTML、CSS、JavaScript 架构，不引入 React 或新依赖。
- 主要修改 `index.html` 中 `#topbar`、`#tbNav`、`#subbar` 的结构、样式和状态更新逻辑。
- 不改动 `data.js`、`data.json`、新闻、公告及任何财务模型文件。
- 不重构导航之外的页面模块，不改变模块名称、排序和数据计算。

## 验收标准

1. 桌面 1280×720、手机 390×844 下，品牌、一级导航和二级 Tab 形成统一固定容器。
2. 页面滚动后，一级和当前页面二级 Tab 均保持可见且可操作，无互相覆盖或跳动。
3. 一级、二级激活状态层级清晰，未选中按钮保持低视觉权重。
4. 二级 Tab 不含数字序号，正文章节编号仍保留。
5. 三大一级模块和全部二级模块均可正常切换。
6. 页面级 `scrollWidth` 等于视口宽度；二级 Tab 仅在自身容器内横向滚动。
7. 主模块滚动位置记忆、个券搜索和主题切换无回归。
8. 自动化测试、JavaScript/Python 语法检查和浏览器控制台检查通过。
