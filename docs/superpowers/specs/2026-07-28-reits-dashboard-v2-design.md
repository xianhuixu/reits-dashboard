# 公募REITs投研面板 v2 深化设计文档

日期：2026-07-28
项目：`reits-dashboard`（GitHub Pages: https://xianhuixu.github.io/reits-dashboard/）
状态：待用户审阅

## 1. 背景与目标

现有面板（v1）已上线：79 只 REITs 全覆盖、三段式结构（KPI+全景热力图 → 5 个 Tab → 配置建议）、iFinD 每日自动取数、GitHub Pages 部署 + 定时任务（周一至周五 17:19）。

v2 目标：结合《REITs投研框架(2).pdf》与经济周期理论（美林时钟 + 基钦/朱格拉/库兹涅茨/康波四大周期），深化为机构级投研面板：

1. 周期耦合分析：四大周期 + 美林时钟判定，与海外 REITs 各资产类型历史表现耦合，推导中国 REITs 长期配置方向
2. 中间 Tab 重构：宏观/行业/个股关注点矩阵（维度一）+ 个券历史/当前/前瞻三视角（维度二）
3. 六因子信号体系：流动性、市场情绪、资金面、业绩达成、利差、股债联动
4. 配置建议升级：周期结论 + 信号佐证 + 触发/退出条件

## 2. 已确认的边界（澄清结论）

| 议题 | 结论 |
|---|---|
| 海外 REITs 数据 | 先探后定：iFinD 能取则每日自动更新；取不到用静态研究数据（手动季度更新） |
| 历史数据深度 | 全量：每只 REITs 拉取上市以来全部日线（2021-06-21 起），技术指标 Python 端算好 |
| 基本面数据 | 混合模式：分红/分派率等试探 iFinD 自动取；运营指标（车流量/发电量/出租率/EBITDA 完成率）做关注点框架 + 红线阈值，数值季度手动维护 |
| 未来预测形态 | 信号驱动 + 手动研判：六因子量化信号自动每日更新，行业/市场研判文字手动月度更新，不做价格预测模型 |
| 实现路径 | 渐进扩展现有单文件架构（fetch_data.py + index.html + data.js），不引入构建步骤/后端 |
| 个券透视交互 | 搜索框 + 筛选条件驱动，非点行进详情 |

## 3. 数据层设计（fetch_data.py 升级）

### 3.1 全历史日线
- 79 只 REITs 全部拉取上市以来日线（start=2021-06-21）
- 保留 raw_cache 断点续跑；缓存已有日期不重复拉（增量更新）
- 新增换手率字段（若 iFinD 接口支持）

### 3.2 技术指标与历史位置（Python 端计算，写入 data.js）
每只 REITs 输出：
- `macd`：DIF / DEA / MACD 柱 + 金叉死叉标记
- `rsi14`
- 价格分位：当前收盘价在上市以来区间的百分位；距 250 日均线乖离率
- 流动性：20 日日均成交额、较 60 日均值的异动倍数
- 累计：`sinceIPO`（上市以来累计涨跌幅）、年化波动率

### 3.3 分红与基本面
- 试探 iFinD REITs 分红/财务接口：成功则输出每只累计分红次数、近 12 个月分红率；失败则字段置 null，前端降级为框架展示
- 季报业绩达成：手动维护 `fundamentals.json`（季度更新），含 EBITDA 完成率、出租率、车流量等；按红线阈值前端自动标色（绿/黄/红）

红线阈值（来自框架 PDF）：
- 产权类：出租率 <90% 或空置率 >12% 或租金偏离 >15% 预警
- 经营权类：流量/出力率低于预测 >10% 或剩余年限不足覆盖本金回收
- 商业不动产类：空置率 >15% 或租金下行 >10% 预警

### 3.4 海外 REITs 指数（先探后定）
- 试探：美国 FTSE Nareit All Equity（含分类型）、东京 TSE REIT、新加坡 iEdge S-REIT、香港恒生 REIT
- 取到 → 每日自动更新；取不到 → `overseas_static.json` 静态研究数据（标注来源与更新日期）

### 3.5 六因子信号打分（Python 端，-2 ~ +2 每因子）

| 因子 | 数据来源 | 打分逻辑 |
|---|---|---|
| 流动性 | 成交额/换手率 | 20 日日均成交额相对 60 日分位 |
| 市场情绪 | RSI + 上涨家数占比 | RSI 区间 + 市场宽度合成 |
| 资金面 | 成交额异动（+主力净流入若可取） | 量能趋势打分 |
| 业绩达成 | fundamentals.json | ≥95% 加分，<90% 减分；无数据记 0 |
| 利差 | REITs 平均分派率 − 10Y 国债 | 相对历史分位（>4.5% 为配置窗口） |
| 股债联动 | 相关性矩阵（已有） | 债性强化/股性强化判定 |

输出：每只 REITs + 三大策略的信号总分与标签（偏强 ≥+1 / 中性 / 偏弱 ≤-1），含各因子原始值供 tooltip 审计。

### 3.6 信号事件检测与回测（Python 端）
- 基于全历史日线检测信号事件：MACD 金叉/死叉、RSI 超买/超卖、成交额异动（>60 日均值 2 倍）、价格突破 250 日线；利差与业绩事件由利差序列 + fundamentals.json 合成
- 输出近 90 日事件流（每日更新滚动窗口）
- 每类事件回测：全历史样本中信号出现后 5/20 交易日的平均收益与胜率，作为"历史命中率"写入 data.js

## 5. 周期耦合分析模块（Tab ②）

### 5.1 四大经典周期定位（cycle_judgment.json，手动月度更新 + 数据佐证）
横向四段时间轴：
- 基钦（库存 3-5 年）：主动去库存尾声/被动补库初期；佐证 PMI 产成品库存、工业企业利润
- 朱格拉（设备投资 7-11 年）：新一轮设备更新周期启动初期（2024 政策起点）
- 库兹涅茨（地产 15-25 年）：下行筑底阶段——压制估值的长周期背景
- 康波（45-60 年）：第五轮萧条期末段、第六轮（AI/算力）导入期——数据中心 REITs 长期逻辑

### 5.2 美林时钟
增长×通胀四象限图，标记当前位置（弱复苏：增长回升+通胀低位），标注三策略各象限占优规律。

### 5.3 海外耦合矩阵（核心图表）
热力矩阵：行=资产类型（住宅/工业物流/数据中心/零售/办公/医疗/基建），列=周期阶段（衰退/复苏/过热/滞胀），值=历史平均超额收益。
- iFinD 取到美国 Nareit 分类型指数 → 自动计算近 20 年各阶段表现
- 取不到 → 静态研究数据（Nareit/NBER 公开口径，标注来源与更新日期）
下方叠加美/日/新/港 REITs 指数走势对比。

### 5.4 对中国映射结论
耦合结论卡片：当前周期组合下海外经验指向工业物流/数据中心/住宅占优 → 映射国内仓储物流、数据中心、保租房，给出 3-5 年配置方向（文字 + 置信度标注）。

## 6. 个券透视（Tab ⑤，搜索/筛选驱动）

- 顶部筛选区：搜索框（名称/代码）+ 策略/板块/产权类型下拉 + 信号标签筛选（偏强/中性/偏弱）
- 筛选结果：卡片列表，每卡迷你三视角摘要（累计涨跌 / RSI / MACD 信号 / 信号总分）
- 选中某只（搜索命中或点卡片）→ 下方展开完整三栏：
  - **历史**：上市以来累计涨跌、成交量/换手率走势、分红记录
  - **当前**：MACD、RSI、历史分位、250 日线乖离、流动性监测、六因子雷达图、重要公告/风险摘录（手动维护字段）
  - **前瞻**：信号标签 + 手动研判文字（标注更新日期）
- 默认视图：信号总表（每只一行：总分、六因子色块、标签，可按分项排序）

## 6A. 策略信号 Tab（⑦，动态信号追踪中心）

按研究框架重新梳理，从静态框架展示升级为动态信号追踪 + 个券信号透视，四个区块：

### 6A.1 三策略信号总览条
防御/周期/成长三条横向信号条：加权信号总分、六因子分项色块、一句话解读（数据驱动生成）。

### 6A.2 信号事件流（动态追踪，核心）
每日信号事件的时间线列表，新事件置顶：
- 事件类型：MACD 金叉/死叉、RSI 超买（>70）/超卖（<30）、成交额异动（>60 日均值 2 倍）、价格突破 250 日线、利差进入配置窗口（>4.5%）、业绩红线预警（来自 fundamentals.json）
- 每条事件：日期、个券/策略、事件类型徽标、触发值、当前信号分
- 筛选：按日期范围、事件类型、策略/板块
- **信号回测**：每类事件标注历史命中率（该信号出现后 5/20 个交易日的平均收益与胜率，Python 端基于全历史日线计算）——让信号可验证而非黑箱

### 6A.3 个券信号透视表
全部 79 只 REITs 的信号明细表：六因子分项（红绿色块 + tooltip 原始值）、总分、标签、最新触发事件；可按任一分项排序，点行跳转 Tab ⑤ 个券透视详情。

### 6A.4 季节性策略日历（静态框架压缩保留）
原分红季（4 月、8-9 月）/解禁/扩募战配内容压缩为一张年度策略日历图 + 要点卡片，标注当前时点所处窗口。

## 7. 信号呈现

- 雷达图：个券详情六因子雷达（-2 ~ +2）
- 信号总表：六因子红绿色块 + 总分 + 标签，可排序
- 策略信号条：Tab ⑦ 顶部三条（防御/周期/成长加权信号分 + 一句话解读）
- 每因子 tooltip：计算口径 + 当前原始值

## 8. 配置建议段重构（五小节）

1. **周期定位**（升级）：PMI/CPI/10Y 三卡片 + 四大周期阶段徽标
2. **长期方向**（新）：海外耦合结论 → 3-5 年赛道配置方向
3. **三策略二级市场验证**（保留 + 增加各策略信号分列）
4. **配置建议**（升级）：每条改为"数据交叉验证 + 信号分佐证 + 触发/退出条件"三段式
   - 触发/退出规则来自框架 PDF：利差 >4.5% 分位加仓；达成率连续两期 <90% 减持；利差收窄至历史 25% 分位系统性减持
5. **风险提示**（保留 + 新增"周期判定错误风险"）
