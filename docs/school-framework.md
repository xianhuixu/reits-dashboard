## 0. 学派定位（不是三家观点的并列清单）

本学派以一条**主脊骨**统摄三家：

```
资金端 → 产品端 → 资产端
        ↓
   分权属估值纪律（产权 ≠ 经营权）
        ↓
   五维破局触发器（趋势确认闸门）
        ↓
   结构配置（三大策略 × 三条主线）
```

- **吸收中金**：负反馈形成/破局机制；「静态低估值陷阱」；五维止跌确认；产权 TTM 分派利差 vs 经营权中债 IRR 利差的官方口径；周频量价与供给雷达。  
- **吸收中信建投**：资金→产品→资产链路；三大策略（流动性/景气度/强原权）× 三条主线（抗周期/高景气·修复/强原权）；「底部配置 / 强于大市」的中期叙事；解禁与商业不动产元年供给框架。  
- **吸收仪表盘原栈**：资产重估假说 \(P = \text{Distribution}/(r_f+\text{risk premium})\)；四条件记分卡（利率/资金中枢/宽度/估值分位）；防御·周期·扩张分类与周期时钟作**宏观背景**，不作独立仓位引擎。  
- **显式丢弃**：用单一 `avgYield` 给经营权贴「极度低估」；用周期 mapping 直接输出多板块「超配」且无视重估暂停；把「已具备配置价值」等同于「趋势已确立 / 全面追涨」。

**中金估值纪律（学派强制采纳）**  
- **产权**：市值加权 TTM 现金分派率 − 10Y（及/或 vs 中证红利息差）+ 历史分位；辅以 P/NAV。  
- **经营权**：市值加权**中债 IRR** − 10Y + 历史分位；**禁止**仅用现金分派率判断「便宜」（现金分派含本金回收）。  
- **定价悖论**：P/NAV↓、分派率↑若无现金流验证 → 市场可读为风险溢价不足 → 继续杀估值。

### 1.2 中信建投 CSC（摘要，详见 `/workspace/csc/framework-brief.md`）

- **链路**：资金端→产品端→资产端；指数基金 / 二级债基 / 险资为需求优先级。  
- **策略×主线**：流动性 · 景气度 · 强原权 × 抗周期 · 高景气/修复 · 强原权扩募。  
- **估值**：产权分派率−10Y 利差分位（**2026-08-26：95.9%**）；经营权 IRR 利差分位（**2026-07-22：60.7%**）。产业园/仓储现金分派约 **5.7% / 5.4%**（08-27）；产权年内约 **−8.2%**（至 08-26）。  
- **立场**：维持行业「**强于大市**」；叙事＝上半年压力释放 → 下半年供需改善 / **底部配置**。  
- **周报 08-29**：全收益周 **+1.4%** 至 **955.3**；产权周 **+2.3%**、经营权 **+0.5%**。

### 1.3 仪表盘原栈（资产重估理论 + live）

- **假说**：实体回报↓ + 流动性过剩 → 资金追逐类债高分红 → 估值中枢上移；公式 \(P=\mathrm{DPS}/(r_f+\mathrm{RP})\)。  
- **四条件记分卡（live，抓取时）**：利率下行趋势 ✓；资金中枢抬升 ✗；市场宽度扩张 ✗；估值分位抬升 ✗ → **score=1 / 重估暂停**。  
- **宏观背景**：`cycle.clock.quadrant≈衰退`；`bond10y≈1.68`；`avgYield≈4.5`（粗锚，**非**卖方分位）。  
- **分类**：防御 / 周期 / 扩张；六阶段市场复盘（上市红利→深度调整→筑底…）。  
- **局限（采纳 CSC/CICC 批评）**：缺个券分派/PNAV/IRR、缺解禁日历、`stratSignals` 信息量低、mapping 与重估暂停易叙事冲突。

## 3. 学派主脊骨与操作定义

### 3.1 一级链路（CSC 骨架）

1. **资金端**：利率与负债成本、险资/OCI、固收+、FOF、理财；成交额中枢、换手。  
2. **产品端**：REITs 指数基金、二级债基扩容、被动工具、会计科目可配置性。  
3. **资产端**：板块基本面、可供分配质量、扩募并表、原始权益人行为。

### 3.2 分权属估值纪律（CICC 口径为主，CSC 交叉）

| 权属 | 主锚 | 辅锚 | 禁止 |
|------|------|------|------|
| 产权 | TTM 现金分派率 − 10Y；vs 红利息差；历史分位 | P/NAV、P/FFO | 用经营权 IRR 反推产权 |
| 经营权 | 中债 IRR − 10Y；历史分位 | 真实分派率（含本金回收，CSC）、车流/电量等高频 | **仅用现金分派率宣称低估** |

### 3.3 五维破局闸门（CICC 五维 × Dashboard 四条件）

| 维 | 内容 | 自动化代理（dashboard） | 「点亮」直觉标准（研究判断，非自动交易） |
|----|------|-------------------------|------------------------------------------|
| ① 基本面 | 分派有效性前提；产权出租/续租；经营权量价运营 | 季报达成率（待接入） | 关键承压板块边际不恶化或验证筑底 |
| ② 估值 | 产权利差处历史极高区提供安全垫，但非充分条件 | 利差分位（待接入）；价格分位 | 产权分位极高 **且** 折价不再单边扩大为恐慌 |
| ③ 量价 | 成交/换手/宽度同步修复；无量反弹＝交易性 | 资金中枢比、20 日上涨占比 | 日均成交中枢抬升 + 宽度改善持续数周 |
| ④ 资金 | 可核验配置行为 > 口头政策；指数/债基/险资/增持落地 | 指数基金 AUM 等（待接入） | 持续净流入或持仓披露验证 |
| ⑤ 供给 | 新发/扩募/解禁被吸收；一二级价差收敛 | 解禁日历、IPO 管线（待接入） | 无失序抽流动性；解禁可消化 |

**闸门规则**：  
- **0–1 维点亮**：仅「观察/极轻分批」，禁止趋势叙事。  
- **2–3 维点亮**（当前典型）：**底部区域分批**，结构重于择时（与 live「重估暂停」兼容）。  
- **≥4 维点亮且量价资金持续**：才允许「趋势确认 / 重估进行中」话术。

### 3.4 结构引擎（CSC 策略×主线，中金中报过滤）

- **流动性策略**：成交活跃、指数成分、机构可买。  
- **景气度策略**：数据中心、交通量修复高速、出租率改善仓储等。  
- **强原权策略**：扩募储备优、增持/信披改善与现金流协同（中金：单纯增持不够）。  
- **主线桶**：抗周期底仓 · 高景气/修复 · 强原权/事件；另设现金/短债缓冲吸收供给冲击。

## 6. Top 5 融合原则（可印在学派首页）

1. **资金为先**：增量资金入口与可核验配置行为，决定负反馈能否打断（CICC）；产品通道（指数/债基/险资）是需求主杠杆（CSC）。  
2. **分权定价**：产权看分派利差分位，经营权看 IRR 利差分位；混用即方法论错误。  
3. **便宜≠买点**：静态低估值在无基本面验证时可推高风险溢价（CICC 估值悖论）；必须过基本面维。  
4. **五维破局闸门**：基本面·估值·量价·资金·供给；未过闸门只许分批低吸，不许趋势牛叙事（融合 DASH 重估暂停）。  
5. **结构配置**：三大策略×三条主线过滤；产业园/仓储高分派只作卫星/左侧，不作抗周期底仓。

## 7. 已裁决的 CICC vs CSC 关键冲突（汇报用）

1. **「强于大市」vs「趋势未确立」** → 学派：**结构性偏多 + 分批**；保留 CSC 评级为引用字段，主文案用破局闸门语言。  
2. **产业园/仓储：中金「高弹性博弈」vs CSC「观望/弱低配」** → **战术卫星、战略非底仓**；加仓绑定出租率/续租证据。  
3. **经营权是否「一样极便宜」** → 两家分位均在 ~53–61%；**否**。仪表盘不得对经营权套用产权利差叙事。  
4. **破局充分条件** → CSC 偏供需/增量资金；CICC 五维更严。学派采用**更严的五维闸门**，把 CSC 增量资金放入第④维。  
5. **周频方向（8 月末反弹 vs 9 月初缩量）** → 以**最新中金周报（09-07）**下调近端风险偏好；月度底部逻辑不因单周回撤自动证伪。
