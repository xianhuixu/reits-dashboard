# 单只基金研究档案

## 交付范围

在既有 `#/detail/CODE` 内扩展，不新增独立产品 Page。经营总表的基金名称可直接进入完整档案；原内联展开仍保留。资料覆盖所有原库内 103 只基金，优先核验和达（180103.SZ）与招商高速（180203.SZ）。不存在行情快照中的新基金也能独立打开档案。

- 基金身份、最新报告期与真实关键指标前置；桌面身份栏跟随现有 `--sticky-offset`，手机取消新增吸顶层，避免挤占阅读区域。
- 五个页内章节：经营、财务与分派、底层资产、持有人、原始报表。只挂载当前章节；有数据才显示章节，长表和其他口径序列默认折叠。
- 图表与本图完整原值表相邻。主图全宽，390px 布局纵向排列、表格本地滚动。百分比转换仅用于显示，原值表保留原单位。
- 独立展示收入、EBITDA、经营现金流、可供分配金额、每份可供分配金额；单季、H1、年度矩阵独立，年初至今与本期不混行。
- 分红事件按源表除息日作散点，完整保留权益登记日、除息日、支付日、收益所属期、税前每份金额和元计总额，不凭日期猜公告日。财务分派字段不当作已派息主图。
- 资产点击进入 `#/detail/CODE/asset/ASSET_ID`，保留基金返回链接、当前资产期别与数值、可匹配同口径的基金/兄弟资产原值。没有项目车流时绝不用基金车流伪装项目值；招商高速项目当前可用标准化数值主要为借款余额。
- 收入/成本构成提供最新报告期按项目公司拆分的原值条形图（单位未载、不同公司不加总）；完整保留经营季报原表、项目表现、收入/成本构成、可供分配计算过程、项目损益/资产负债、费用、扩募、客户集中度、持有人结构/主要持有人/份额事件。
- 原行情、估值与交易信号 UI 仍在同一路由的折叠区，打开后执行既有图表 resize；档案不向这些计算写数据。

## 源库与可重复导出

```sh
python3 scripts/export_fund_archives.py /absolute/path/source.db
```

使用 `mode=ro` 加 `PRAGMA query_only=ON`。输出 `research/fund-archives/CODE.json` 与 `manifest.json`；没有机器路径写进前端数据。相同源库字节重复导出得到完全一致的 JSON（无浮动导出时间）。`manifest.json` 保存整个源库 SHA256、全部 36 张表的字段非空/有效/零值计数、逐表行数、是否接入及逐基金覆盖。32 张表导出，另外 4 张未接入档案：`macro_series`、`price_risk`、`price_move` 由已有模块管理，`market_valuation` 缺估值方法/来源等，不引入新估值口径。

按基金分片，用户只打开哪只才取哪只；全量约 25MB，最大单只约 0.68MB（未压缩），初始页不加载全量档案。单只页面章节切换不额外取数，成功请求缓存、失败后可重试，旧异步响应不会覆盖新基金。

## 口径与质量

- `ops_metric.asset_id=ALL` 为基金；项目必须通过 asset_id 与 code 的资产归属校验，发现原 `level` 552 行错标，保留原标签、不混进基金曲线。经营原表自身的范围标签另存 `original_scope`，不丢原文。
- financials 空 asset_id 仅在原层级确为基金时作为基金；1,259 条空 asset_id 的项目公司记录留在完整原表、标记“归属待核”，不硬归到基金或任意项目。
- 趋势按源表、资产、指标、单位、统计口径、税标记、期间粒度拆成独立序列；缺期不补值、不插值，未知税口径只画原值散点、不连线，不能因双方都“未说明”认定可比。不计算新同比、同店、IRR、LTV、达成率或持有人净增减。
- financials 的 actual_distribution/dps_actual 不进已派息主图。共 179 个零值字段与非零分红事件存在直接或潜在冲突，保留零值并标记“待核”，分别记录“收益期间对应”或“仅日期同年，财年归属待核”；不按支付年覆盖财年分配字段。179 是字段数，不是基金数、报告数或已核实金额差异数。非零分派财务字段同样仅作隔离原值展示，不作为已付事件。
- 508008.SH 2026Q3 仅期间车次 2,086,000，不换算日均；180203.SZ 对应日均 19,692 车次/日、通行费 13,551.5 万元，分指标、分单位；水务默认营业收入。
- 权益乘数不写成LTV，经营权分派提示可能含本金，绝不拿分派率替代IRR。
- 退出日为空仅表示退出信息待核；扩募与同店区别保留。未披露不转成 0。

## 尚存的数据缺口（集中披露于页面）

1. 源库没有逐报告期原公告 URL、页码。矩阵表头保留报告期并注明无法直达原文；只展示数据库真实存在的交易所**项目入口**，不伪装为报告链接。
2. forecast 没有单位、来源/假设日，年度/残缺年预测仅列原值与起止月，未与实际金额硬对照、未拆成季度预测。
3. appraisal_assumption 缺日期与项目范围，作为独立原值表，不强作评估假设与实际达成率。
4. 构成、计算、项目资产负债等部分原表没有单位字段，明确只列原值，不自动与万元财务指标相加。原始同比仅为追溯列，未作为核验同比。
5. 项目主体补充信息只按同基金完整资产名精确匹配，别名不强行关联；基金资产页另保留完整原始列表，避免未匹配资料被吞掉。
