## 2. 增长 × 利率时钟（P0-2）· `cycle_judgment.json.rateClock`

> **2026-09-30 口径校准**（`methodVersion = "2026-09-30"`）：利率轴来自固收 PM 的中债 10Y 日频回测，增长轴与社融脉冲来自宏观分析师的月度回测；本节取代 2026-09-29 的「±10bp 固定死区 + PMI 3 月均 vs 50 + 49.5–50.5 边界」旧口径。

由 `update_cycle_data.py`（CI 每日第一步）调用 `rate_clock.py` 自动计算：

| 轴 | 口径 | 数据源（真实） |
|---|---|---|
| 利率 | 10Y 国债 **60 个交易日**变化 d；σ = d 的滚动 **250 交易日**（≈1 年）标准差；**进入线 T = max(5bp, 0.7σ)**，**退出线 = T/2**（T 触底时为 2.5bp）；**5 个交易日确认** | 东财 `RPTA_WEB_TREASURYYIELD` · `EMM00166466`（中债 10Y，2015-01 起日频） |
| 增长 | g = 制造业 PMI − 近 **36 个月**均值（含当月）；z = g 在 **60 个月**滚动窗口内标准化；看 z 的 **3 个月均值 z3**；**±0.5σ 进入 / ±0.25σ 退出**；**连续 2 个月确认** | 东财 `RPT_ECONOMY_PMI`（国家统计局；接口无新订单分项 → 用 **PMI 总指数**） |

### 2.1 利率轴：动态死区 + 滞回 + 5 日确认
- 当日原始信号：d > T → 上行；d < −T → 下行；已在上行时 d < +T/2、已在下行时 d > −T/2 → 走平；其余保持。
- 原始信号与当前状态不同时开始计数，**连续 5 个交易日**不同才切换，中断即清零（与 PM 的 `dz_backtest.py` 中 `hyst(0.7, confirm=False, floor=5, persist=5)` 逐日一致）。
- **不加 60 日均线条件**：回测显示加上后切换次数、滞后几乎不变（4.8 次/年 · 滞后 60 日），没有增益。
- 预期统计（PM 回测：中债 10Y 2015-01~2026-09-29，σ 可用起 2016-03-31，13 个 ≥30bp 拐点）：**约 4.8 次切换/年、状态持续中位 50 个交易日、<10 日的来回切换占 6%、拐点识别中位滞后约 60 个交易日**。
- 滞后主要来自 **60 日窗口**本身；20–40 日窗口会更快，但噪声更大，**本期不采用**。
- **本仓复核**（`rate_clock.rate_backtest`，同一东财序列）：2016-03-31~2026-09-29 共 2627 个交易日，**50 次切换 = 4.8 次/年**，状态中位 **50** 日，来回切换 **6%**，拐点滞后中位 **60** 日（13 个拐点）；逐日状态与 PM 脚本 **0 差异**。结果写入 `rateClock.backtest`。
- 字段：`d10y60bp` / `sigma60bp` / `thresholdBp` / `exitBp` / `thresholdFloored` / `rateDir`（up/down/flat）/ `rawRateDir` / `ratePending`（待确认天数）/ `rateDistance`（距最近切换线的 bp、文案、`critical`：距离 ≤ 0.2×进入线或处于确认期）。

### 2.2 增长轴：PMI 偏离趋势 z 分数 + 滞回 + 2 个月确认（2026-09-30 已回测）
- z3 ≥ +0.5 → 高于趋势（`growth.state=1`，level=强）；z3 ≤ −0.5 → 低于趋势（−1，弱）；已在高于/低于趋势时，z3 回到 ±0.25 以内才退回「趋势附近」（0）。
- **2 个月确认**（与利率轴 5 日确认同理）：月度原始信号与当前状态不同时开始计数，**连续 2 个月**不同才切换，中断即清零（`rate_clock.growth_confirm_step`）。字段 `growth.rawState` / `growth.pending`（待确认月数）/ `growth.confirm`（`count`/`need`/`earliestMonth`/文案，如「退回中性确认 0/2 · 需连续 2 个月低于 0.25σ，最早 11 月数据可能改变读数」）；history 每月带 `growthPending`。
- **回测（宏观分析师，2016-01~2026-09 月度）**：约 **0.9 次切换/年**、状态持续中位 **6 个月**、**<2 个月的来回切换 0 次**、「趋势附近」占 **51%**；本轮进入「高于趋势」由 2026-04 **推迟到 2026-05**，当前读数不变（高于趋势），**最早 11 月数据**才可能改变读数。写入 `method.backtestGrowth`。
- **本仓复核**（`rate_clock.growth_backtest`，东财 2008-01 起 PMI 全样本）：2016-01~2026-09 共 129 个月，10 次切换 = **0.93 次/年**，<2 个月来回切换 **0** 次，本轮进入月 **2026-05**（与分析师一致）；状态中位 5 个月、趋势附近占 48%（与分析师 6 个月 / 51% 略有差异，推测来自 z 窗口预热起点不同，见下条；分析师样本自 2012-01 起算）。写入 `rateClock.growthBacktest`。
- **已移除「49.5–50.5 边界」规则**，由上面的「趋势附近」状态取代。
- 距退出线 ≤ **0.05σ** 标「临界」（`growth.critical`），前端时钟卡用两个小圆点显示确认进度（如「退回中性确认 0/2」），置信度以灰色小标签放在卡片上（不进首页结论横幅）；确定象限置信度降为「中低」。
- 趋势（Q4 滞胀/复苏拆分用）= z3 较上月变化（±0.05σ 死区）。
- 与宏观分析师 `growth_axis.csv` 逐月核对：**2020-01~2026-09 共 81 个月，dev / z / z3 / 状态完全一致**；2018–2019 的 z 有差异，原因是分析师样本从 2012-01 起算（z 窗口预热不足），本仓用东财 2008-01 起全样本，状态仅 2018-03/04 两个月不同。分析师参考值 **2026-09 PMI 50.1、偏离 +0.42、z 0.72** 与本仓一致；z3 = 0.26（仅比退出线 0.25 高 0.01σ → **临界**）。

### 2.3 象限、过渡期与「信号切换」
- 两轴都有方向（利率上行/下行 且 增长高于/低于趋势）→ `state="definite"`，给出象限：Q1 繁荣（强+上行）、Q2 复苏/泡沫（强+下行）、Q3 衰退（弱+下行）、Q4 滞胀/复苏（弱+上行）。
- 任一轴处于走平 / 趋势附近 → `state="transitional"`（「利率走平·过渡期」/「增长趋势附近·过渡期」/ 两者皆是），`quadrant=null`，`confidence="低"`，只给 `leanQuadrant`（利率走平时取 d 的符号，增长趋势附近时取 z3 的符号）作参考。
- `summary`：如「增长高于趋势（临界）· 利率下行」。
- `signalSwitch`：读数与上一版不同就记录一次切换；上一版口径版本不同 → `cause="methodology"`，附注「**9-30 起改用新口径，这次切换来自口径更新，不代表市场突变**」。标签保留 14 个自然日（`active`），周期页时钟卡和配置页状态行都会显示。
- `history`：逐月末重算（利率轴取月末交易日状态，增长轴取当月及以前最新 PMI），保留 24 个月；旧口径条目不再混入。SVG 横轴 Δ10Y(bp)、纵轴 z3(σ)，灰带为进入/退出线。
- `conflictFlags`：规则不变（硬冲突只来自确定象限；过渡期全部降为 `reference`）。增长临界时文案追加「增长处临界」。
- **当前判定（asOf 2026-09-29，计算 2026-09-30）**：10Y 1.667%，60 日 **−7.4bp**；σ 6.9bp（历史中位 17.2bp）→ 进入线触底 **5bp**、退出线 **2.5bp**；5 日确认已满足 → **利率下行**，距退出（转走平）还差 **4.9bp**，不临界。PMI 2026-09 50.1，z3 **+0.26σ** → **增长高于趋势（临界）**。→ **Q2 复苏/泡沫（确定，置信度 中低）**。相对旧口径（利率走平·过渡期，最近 Q3）属于**口径切换**。自动提示：**产业园「观望/弱低配」处美国先验最佳象限 Q2 → 复核（watch）**；消费不再触发 Q3 雷区参考；无全市场背景提示。

### 2.4 社融脉冲 · 领先预警（`cycle_judgment.json.tsfImpulse`，单独卡片，**不并入增长轴**）

- 数据：商务部数据中心 `data.mofcom.gov.cn` 社融增量（与 akshare `macro_china_shrzgm` 同源，目前**只到 2026-04**）；取数失败沿用 `macro_series.json` 缓存（`seriesOrigin=cache`）；缓存也没有时 `status="pending"`、`label="待接入"`，**不给任何数值**。

## 3. 股/债 Beta（P1-3）· `data_research.json.correlation.betas`

`beta_calc.py`（由 `fetch_data_em.py` 与 `fetch_data.py` 调用，数据源沿用各自行情源：腾讯 K 线 / iFinD）：

- 周频（W-FRI）收益；对 **000300.SH 沪深300** 求股 Beta，对 **000012.SH 上证国债** 求债 Beta；另把周收益对周 Δ10Y（bp，取自 `macro_series.json`）回归，结果 ×10，得到 `sens10y`，即「10Y 每上行 10bp 对应的周收益 %」。
- 主窗口 **104 周**（腾讯接口单次 500 根日线，CI 无持久 hist_cache，实际约 100 周，以 `weeksAvailable` 为准；少于 40 周置空），另算板块 **52 周滚动** Beta，用来观察 Beta 漂移。
- 分类：中国 REITs 与股指相关性很低、Beta ≪1，所以**不用**美国的「Beta>1 = 偏股」。改为截面相对排序：`score = z(股Beta) − z(债Beta)`，前 1/3 为偏股，后 1/3 为偏债，中间为中性。
- 与人工策略标签交叉：防御型应偏债，周期型 / 扩张型应偏股；落在相反一端的记 `disagree` 并列表。
- 前端：策略分类页「股/债 Beta 定位」卡，包括散点（债 Beta × 股 Beta，菱形 = 不一致）、52 周滚动折线、板块表和不一致清单。资产相关性页的相关散点保留，并在该卡加了链接。
- **当前状态：pending**。box 无法访问腾讯 K 线（WAF 拦截），本 PR 没有生成任何 Beta 数值；`scripts/sync_static_embeds.py` 只写入 `status=pending`。合并后，CI 下一次运行 `fetch_data_em.py` 会用真实行情计算。单元测试使用合成夹具（`tests/test_beta_calc.py`），夹具只用于测试，不作为数据。

## 7. 已知局限
