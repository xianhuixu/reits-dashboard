# REITs Dashboard 设计验收记录

日期：2026-10-07。基于主分支 `187c763` 更新，保留原始行情、研究数据、配置规则及原始权益人地域口径。

## 设计目标

面向专业投资者，将信息按“市场判断—证据—基金明细”组织。采用深蓝研究侧栏、浅灰工作区、白色证据面板及统一字体层级；通过真实行情曲线、紧凑地图和可选择的历史阶段形成视觉重点。

参考 [Webby 官方评审维度](https://www.webbyawards.com/judging-criteria/)检查内容、结构与导航、视觉、功能、交互和整体体验。Awwwards、Webby、FWA 获奖须由各奖项正式评审决定，本记录不将内部验收等同于获奖认证。

## 改动与复查

1. 修正样式加载顺序，消除旧样式覆盖工作台设计的问题。统一页面标题、导航、间距、面板边界与三套主题。
2. 将配置判断与真实市场走势并列展示，四项关键状态采用连续信息带；长判断依据通过原生详情控件展开。
3. 用原生 SVG 呈现价格指数，保留区间重基准为 100 的既有计算，支持日期悬停、键盘浏览及数据表。新增首页序列文件是研究源数据的等值派生文件，并加入数据一致性校验和每日生成流程。
4. 地图默认展开，接近可见区域时加载。城市标记缩为环形结构，保留按原始权益人注册城市定位及资产类别筛选，减少重叠。
5. 复盘改为阶段选择与详情联动，支持键盘操作。配置理由表格调整列宽并换行，避免长文本被截断。
6. 逐轮修正移动菜单、辅助文字对比度、夜间选中态、区域命名与表格键盘访问问题。同步修正镜像发布中字体和数据文件遗漏。

## 验证范围

- 自动测试：83 项通过，包含指数重基准、原始数据不变性、派生序列与源数据一致性及既有研究口径测试。
- 响应式：320、390、768、1024、1440、1920 像素宽度，四个主栏目合计 24 个组合，无页面级横向溢出。
- 交互：趋势区间与键盘、复盘阶段与键盘、地图类别及重置、三套主题、移动菜单导航。
- 无障碍：axe WCAG 2 A/AA 自动检查覆盖四个主栏目与三套主题，以及加载后的地图。自动检查不能代替完整人工辅助技术测试。
- Lighthouse 本地压缩预览：性能 95、无障碍 100、最佳实践 100；移动端模拟 LCP 2.9 秒，CLS 0.006。单次实验室测量随机器和网络波动，不代表线上真实用户指标。
- 首页行情序列由约 1.06 MB 完整研究文件缩为 4,795 字节，250 条观察与源序列逐项一致。没有修改原始财务 JSON、估值参数或配置计算规则。
